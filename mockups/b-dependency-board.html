Trophy dependency board

Every trophy is a node, every requirement is an edge. Read the numbers left to right: that is the same route order as direction A. The graph answers "what blocks what" at a glance. The price is on the page too: long edges, crossings, and a width a phone PDF cannot hold.

What it gives you

You see the whole run in one screen. Fatality trophies clearly hang off the Krypt, and the two story run locks stand out before you press start.

What it costs

Two edges cross no matter how you lay this out. That gets worse with real 50-trophy lists, where v1 lives.

What it cannot do

A graph does not tell you what to do at 9pm tonight. You still read it against an order that lives somewhere else, usually in the guide text.

Print verdict

This shape does not survive A4 phone reading. Edges under 1px column width become noise. It would ship as a screen-only extra or not at all.

the trade, stated plainly

The graph is a great answer to a question the PDF never asks. Direction A keeps dependency knowledge as tags on steps, which is where a player standing in a menu can use it. If Kriday still wants the graph after this page, the honest version is a small per-chapter diagram in the PDF appendix, not one whole-game board.
