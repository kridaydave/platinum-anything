# ADR 0001: v1 form

Status: clarified for v1 following the agent-independent product decision
Ticket: [#5](https://github.com/kridaydave/platinum-anything/issues/5)

## Decision

V1 consists of a reusable prompt and a phone-readable PDF template that can be given to any capable agent. The player supplies a PlayStation game, current position and chosen modes. The agent researches and writes a sourced route using the template; an available renderer produces the PDF. Kriday's first acceptance case is his Mortal Kombat run. He transfers the PDF to his phone and marks progress with his PDF reader. The PDF is usable offline; research needs internet access. Progress annotations are manual and do not sync back.

The product does not launch or bundle an agent, require a particular provider or model, or provide accounts, billing, hosting, or stored progress. A chosen agent may have its own account, credentials, costs and permissions, including an API key. If it lacks web research, file creation or rendering, the player needs another suitable tool for that step and the limitation must be made explicit.

## Alternatives and portability

A local web app and standalone CLI add infrastructure or a launcher to a workflow that can use an existing agent. A deployed site adds hosting and multi-user work outside personal v1. Route structure, source attribution and layout may inform a future site, subject to source rights. A hosted service would need its own generation, credential and cost handling and any desired progress storage; these are not part of v1. Respect access restrictions and reuse rights: attribution alone does not grant republication rights.

The PDF is a static route with manual annotations. If future requirements demand interactive dependencies, automatic progress tracking or live help, revisit the form. The original harness-specific assumption is superseded by this clarification; it does not select a generation backend.
